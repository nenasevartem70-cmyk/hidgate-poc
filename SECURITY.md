# Security policy

This repository is a security-research crash PoC for a patched vulnerability.
It is not a jailbreak, exploit chain, or weaponized tool.

- Do not run it on a device you do not own.
- It will panic the kernel and reboot the device.
- It does not provide kernel read/write or persistence.

For vulnerabilities in Apple products, report them through Apple's security
reporting process: https://security.apple.com/submit

For issues with this PoC itself, open a GitHub issue.
