Overview

hidgate-poc documents two kernel bugs on an iPhone XR (A12) running iOS 18.7.2: the IOHIDFamily fast-path race (CVE-2026-28992) and the AppleJPEGDriver decoder timeout UAF (CVE-2026-20687). Both are reachable from the normal app sandbox without entitlements.

IOHID

Crash-only

FastPath open/teardown race. The provider-side object is not reachable by userland sprays, and copyEvent never delivers an event on this SPU.

AppleJPEG

UAF + reclaim

Deferred JpegRequest UAF, a controlled 10 s timeout, and same-type reclaim without a panic.

Target

iOS 18.7.2 / A12

iPhone XR (iPhone11,8), xnu-11417.140.69.702.20~1.

Kernel control status

No kernel read/write yet. The current rung is a controlled free and a same-type reclaim in AppleJPEGDriver. The public PoC's direct *(*(request+0)+0x28)() path is PAC-protected on A12 (autda + blraa), so the next gate is a double-free/write primitive, not a fake vtable.

Research roadmap

From a reproducible crash to a controlled primitive. Control is the active stage; the rest is still open.

UAF → phase A trigger → control → KASLR → kernel r/w → jailbreak.

The race

sel0 gates on entitlement keys in the caller-supplied dictionary. sel1 drops provider state without the lock, while sel2/open paths walk the same provider-facing objects.

Two locking domains, one provider: teardown frees state while the open path walks it.

The panic

The crash is a kernel data abort on a virtual call through a corrupted object pointer. The backtrace contains IOHIDFamily and AppleSPU.

Crash is not control. The repository documents a controlled free and a same-type reclaim, not kernel read/write. There is no PAC/PPL/SPTM bypass, no persistence, and no jailbreak. The test builds intentionally panic or wedge the kernel.

Patch timeline

Vulnerable through 18.7.1 · tested on 18.7.2 · patched in 18.7.9 and 26.5.

Build it yourself

No prebuilt IPA is committed. Build the app and package an unsigned IPA on macOS:

# clone git clone https://github.com/nenasevartem70-cmyk/hidgate-poc.git # build the app + IPA cd hidgate-poc make # outputs build/Payload/hidgate4.app build/hidgate4-unsigned.ipa

Sign the IPA with your own certificate or sideloading workflow before installing.
